## Descripción del Proyecto
Aplicación en PyQt5 y Pandas para la empresa salvadoreña de comercialización multisede (San Salvador, Santa Ana, San Miguel, La Libertad y Sonsonate), que incluye análisis estadístico e interfaz gráfica interactiva con gráficos de Matplotlib.
